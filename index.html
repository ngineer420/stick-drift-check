About Stick Drift Check

Stick Drift Check is a free, no-signup set of controller tests that run entirely in your browser using the Gamepad API. Connect an Xbox, PlayStation, Nintendo Switch Pro, or generic USB/Bluetooth controller, press any button so the browser can see it, and every tool on this site comes to life — no driver, no download, no account.

The five tools split cleanly by what you're trying to find out. The stick drift test measures each analog stick's resting position over a three-second window and flags DRIFT when a released stick wanders outside a small threshold. The deadzone visualizer plots both sticks against an adjustable deadzone ring so you can see whether a game would swallow that drift or not. The button test shows live pressed state for every button the pad reports, the trigger test gives analog travel bars for LT/RT and L2/R2, and the rumble test fires a haptic pulse at both vibration motors.

Nothing you do is uploaded. All detection and analysis happen locally on your device, and no controller data ever leaves your browser.
